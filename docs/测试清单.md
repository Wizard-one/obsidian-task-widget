# 测试清单

每个版本发布时更新本文件,列出**这次改动需要在手机上验证什么**。
✅=已验证 / ⬜=待验证。装新 APK 后请按当前版本清单逐条测。

---

## v1.9.15(当前)

我已自测(自动化):全部单元测试通过,release 编译及签名通过。
下面需要在手机上确认 widget 的实际筛选结果:

### “今天 + 已过期”改为 happens on or before
- ⬜ **开始于今天/过去,截止在未来**:应显示(例如 `🛫 昨天 📅 下周`)
- ⬜ **截止于今天/过去,开始在未来**:应显示
- ⬜ **开始和截止都在未来**:不应显示
- ⬜ **只有计划日期 ⏳、没有开始/截止日期**:不应因计划日期而显示
- ⬜ **没有开始和截止日期**:不应显示
- ⬜ 升级安装后无需重扫整个 vault;已有 v3 缓存可从任务原文补解析日期

## v1.9.5(历史)

我已自测(自动化):73 个单元测试全绿(含删除/解析),release 编译通过。
下面需要你在手机上点一下确认(我无模拟器,widget/UI 实机行为测不了):

### 删除任务
- ⬜ **App 列表长按删除**:浏览全部任务 → 长按任意任务 → 弹菜单 → 删除 → 该行消失,去 Obsidian 确认那一行已从 .md 删除
- ⬜ 长按菜单里"在 Obsidian 打开"能跳到对应笔记
- ⬜ **看板/日历视图**里长按任务同样能删除
- ⬜ **编辑页删除**:点任务(或 widget 里点任务)进编辑页 → 底部"删除任务" → 确认 → 删除
- ⬜ 说明:**widget 无法长按**(Glance 不支持),widget 里删除 = 点任务进编辑页再删

### 完成提速(乐观隐藏)
- ⬜ widget 点方框完成:该行**几乎立即**消失(不再等一两秒),Obsidian 里该行已打勾 + ✅ 日期
- ⬜ 快速连点完成多条:每条都及时消失,不串行卡顿

### 编辑刷新
- ⬜ widget 点任务 → 编辑页改截止日期 → 保存 → 返回桌面,widget 上该任务日期已更新(不需手动刷新)

## v1.9(历史)

本次修的 5 件事 + 需要重点回归的项:

### 新增 / 修复
- ✅ **Widget 不再 "Can't show content"**:在大 vault(2000+ 文件)下,主屏幕添加"任务清单""接下来""每日议程""月+议程" widget,都能正常显示,不再报错。超过 50 条时末尾显示"还有 N 条…"
- ⬜ **添加任务立即出现在总览**:App 里打开"浏览全部任务" → 用 ➕ 快速添加一条 → 返回列表,新任务**立即出现**,无需手动刷新
- ✅ **快速添加带日期/优先级**:快速添加对话框里能点"📅 截止""🛫 开始"选日期、选优先级(🔺⏫🔼🔽⏬);添加后去 Obsidian 检查该行格式正确(如 `- [ ] 写报告 ⏫ 🛫 2026-07-12 📅 2026-07-20`)
- ⬜ **自然语言仍有效**:快速添加输入"交房租 明天"不选日期,写入的行带正确的 📅 明天日期
- ⬜ **inbox 任务不重复**:快速添加后,总览/widget 里该任务只出现一次(不因缓存键不同而重复)

### 回归(上几版修的,顺带验证没坏)
- ✅ 扫描速度:App 里"重新扫描"第二次起是秒级(第一次建缓存稍慢)
- ⬜ widget 勾选任务后该行立即消失,不残留勾选状态
- ⬜ 循环任务出现在"今天/已过期"(只有 ⏳/🛫 无 📅 的也算)
- ✅ 看板视图可切换"按日期/按优先级"排序
- ⬜ 重启手机后 widget 不卡在"加载中"
- ✅ 全局排除路径对列表/看板/日历/widget 都生效
- ✅ 编辑页"在 Obsidian 中打开"能跳到对应笔记
