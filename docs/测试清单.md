# 测试清单

每个版本发布时更新本文件,列出**这次改动需要在手机上验证什么**。
✅=已验证 / ⬜=待验证。装新 APK 后请按当前版本清单逐条测。

---

## v1.9(当前)

本次修的 5 件事 + 需要重点回归的项:

### 新增 / 修复
- ✅ **Widget 不再 "Can't show content"**:在大 vault(2000+ 文件)下,主屏幕添加"任务清单""接下来""每日议程""月+议程" widget,都能正常显示,不再报错。超过 50 条时末尾显示"还有 N 条…"
- ⬜ **添加任务立即出现在总览**:App 里打开"浏览全部任务" → 用 ➕ 快速添加一条 → 返回列表,新任务**立即出现**,无需手动刷新
- ✅ **快速添加带日期/优先级**:快速添加对话框里能点"📅 截止""🛫 开始"选日期、选优先级(🔺⏫🔼🔽⏬);添加后去 Obsidian 检查该行格式正确(如 `- [ ] 写报告 ⏫ 🛫 2026-07-12 📅 2026-07-20`)
- ⬜ **自然语言仍有效**:快速添加输入"交房租 明天"不选日期,写入的行带正确的 📅 明天日期
- ⬜ **inbox 任务不重复**:快速添加后,总览/widget 里该任务只出现一次(不因缓存键不同而重复)

### 回归(上几版修的,顺带验证没坏)
- ✅ 扫描速度:App 里"重新扫描"第二次起是秒级(第一次建缓存稍慢)
- ⬜ widget 勾选任务后该行立即消失,不残留勾选状态
- ⬜ 循环任务出现在"今天/已过期"(只有 ⏳/🛫 无 📅 的也算)
- ✅ 看板视图可切换"按日期/按优先级"排序
- ⬜ 重启手机后 widget 不卡在"加载中"
- ✅ 全局排除路径对列表/看板/日历/widget 都生效
- ✅ 编辑页"在 Obsidian 中打开"能跳到对应笔记

## 与 TaskForge 的行为对齐(持续核对)

逐条核对我们的行为是否与 TaskForge 一致,不一致的记录取舍:

| 行为 | TaskForge | 本项目 | 对齐? |
|---|---|---|---|
| 任务清单 widget 勾选即完成写回 | ✅ | ✅ | ✅ |
| widget 大列表截断 | ✅(截断) | ✅(50 条) | ✅ |
| 快速添加带日期/优先级 | ✅ | ✅(v1.9) | ✅ |
| 循环任务完成生成下一次 | ✅(完整 RRULE) | 常见 every… 语法 | 部分 |
| 实时文件监听 | ✅(全盘权限) | 进入即刷新(SAF) | 有意不同 |
| 完成日期 ✅ 写回 | ✅ | ✅ | ✅ |
| Dataview / TaskNotes 解析 | ✅ | 识别,循环重排仅 emoji | 部分 |
| 每任务精确提醒 | ✅ | 每日摘要 | 部分 |

**待对齐的候选(下一步可做)**:
